# Meme Card Battle — Backend

Серверная часть карточной онлайн-игры **Meme Card Battle**. Отвечает за авторизацию игроков, игровую логику расчета боя, экономику, систему друзей, работу с кейсами и взаимодействие с базой данных.

> **Фронтенд-репозиторий:** [Meme-Card-Battle-Frontend](https://github.com/BoltHack/Meme-Card-Battle-Frontend)

---

## Стек технологий

- **Платформа и язык:** Node.js, TypeScript
- **Фреймворк:** Express
- **База данных:** MongoDB (Mongoose)
- **Аутентификация:** JWT (Access & Refresh токены)

## Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd Meme-Card-Battle-Backend
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Настройте переменные окружения:**
   Создайте файл `.env` в корневой директории проекта и заполните его по следующему шаблону:

   ```env
   # Подключение к MongoDB
   MONGODB_URL=mongodb+srv://<username>:<password>@cluster.mongodb.net/mcb

   # Секретные ключи для генерации JWT-токенов
   ACCESS_TOKEN_SECRET=your_access_token_secret
   REFRESH_TOKEN_SECRET=your_refresh_token_secret

   # Почтовый сервис для восстановления доступа к аккаунту
   USER=support@example.com
   PASS=your_email_app_password

   # Настройки сервера
   BACKEND_PORT=3000
   NODE_ENV=development
   ```

4. **Запустите сервер в режиме разработки:**
   ```bash
   npm run dev
   ```

### Как получить значение для `PASS` (Google App Password)

1. Перейдите в [Управление аккаунтом Google](https://myaccount.google.com/).
2. Откройте раздел **«Безопасность»** и включите **двухфакторную аутентификацию** (если она еще не активна).
3. В меню управления аккаунтом найдите раздел **«Пароли приложений»** *(можно воспользоваться строкой поиска вверху страницы)*.
4. Создайте новый пароль приложения: укажите любое название (например, `MemeCardBattle` или `backend`).
5. Скопируйте сгенерированный 16-значный пароль и вставьте его в файл `.env` в переменную `PASS` **без пробелов**.

## Основные модули сервера

- **Auth & Security:** Регистрация, вход, обновление пары JWT-токенов, смена пароля, восстановление аккаунта по почте и удаление профиля.
- **Battle Engine:** Серверный расчет урона с учетом показателей атаки/защиты карт, накопления ульты (x2 урон при 100%) и начисления опыта/наград за победу.
- **Shop & Inventory:** Покупка кейсов за коины, генерация выпадения карт и управление коллекцией игрока.
- **Social:** Поиск пользователей по никнейму, управление списком друзей и обработка приглашений в бой.
